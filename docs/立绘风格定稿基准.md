# 识尘 · 立绘风格定稿基准（Style Bible）

> **本文件是对「已定稿立绘」的逆向总结，效力高于一切临时口头描述。**
> 以后新角色 / 返修，一律先读本文件，按第 4 节模板出图、按第 5 节自检。
> 目标：**别再一次次试错**——把一致性前置到 prompt 里，而不是靠后期修补。

## 一、画风锚点（全 16 张必须完全一致）

### 1.1 渲染风格
- **日系角色插画 · 半厚涂**（semi-realistic anime illustration / soft painterly cel shading）。
  介于「动画赛璐璐」与「写实厚涂」之间：有明确结构，但过渡柔和。
- **线稿用有色线**：深色系（深褐 / 深蓝 / 深紫），线宽细、收敛，**不描粗黑边**。
- **上色三层**：底色 → 柔和渐变过渡 → 局部高光；除布料大结构外**阴影不硬边**。
- **材质必须可辨**：呢料哑光、丝绒吸光、真丝反光、皮革高光、粗针织有绒感。
  这是这套图「贵」的地方，比脸更重要。

### 1.2 画布与构图
- **竖构图，比例 2:3**。生图用 **1536×2304**（实测上限；2048×3072 会被服务端拒绝）。
- **纯白底 `#FFFFFF`**（或用透明 PNG）。**不要背景、不要地面阴影、不要环境光晕**。
- **全身站姿，人物居中**；头顶留白约 8%，脚底留白约 4%；四肢完整不裁切。
- **平视视角**，无透视夸张、无仰/俯角。
- **头身比 7–7.5**（少年/少女角色 6.5–7）。
- 所有角色**同比例、同底色、同机位**，并排看要像同一本画册。

### 1.3 光影与肤色
- **柔光**：主光从左前上或右前上，辅光很弱；不向背景投影。
- **肤色 = 冷调象牙白**（约 `#F5E8E2` / `#EFE3DC`）。
- **肤色必须均匀干净**——不许白斑、不许青紫块、不许「磨平」成塑料。
- ⚠️ **绝对禁止用「全局提亮/抬白场」来修肤色**（会把额头 235–248 的皮肤推成纯白 → 白癜风块）。
  提亮只允许在**面部局部**且带掩膜。

### 1.4 颜色配额（本企划最强识别符）
- 整体**低饱和、灰调**（饱和度普遍 ≤ 40%），**不要鲜艳、不要高对比**。
- 每个角色**恰好一处高辨识度重点色**，面积 ≤ 全图 15%。
- 配色母题：**「洁净的灰白底 × 一处锋利的颜色」**。

## 四、生图 Prompt 模板（直接复制）

### 4.1 通用风格前缀（STYLE — 每张都必须带）
```
anime character illustration, semi-realistic painterly cel shading,
clean fine colored lineart, soft gradient shading, detailed fabric textures,
cool ivory skin tone, even clean skin, soft frontal-top lighting,
pure white background (#FFFFFF), no ground shadow, no background elements,
full body standing pose, front view, eye-level, centered, 2:3 vertical composition,
natural anime proportions about 7 heads tall,
muted desaturated palette, exactly one vivid accent color
```
**调用参数**：`quality: high`，尺寸 `1536×2304`。

### 4.2 负面清单（NEGATIVE — 每张都必须带）
```
photorealistic, 3D render, western cartoon, chibi, thick black outlines,
harsh rim light, glowing effects, lens flare, gradient background, scenery,
ground shadow, cropped limbs, extreme perspective, exaggerated pose,
oversaturated colors, high contrast, plastic skin, smooth blurred face,
freckles, moles, skin blemishes, uneven skin patches, white blotches on face,
extra fingers, deformed hands
```
> 「AI 归一化」防范（针对本企划）：**不要削发量、不要删肩章/徽章、不要改披风形状**——
> 一切推演都必须以**原画或已定稿立绘为 i2i 输入**，禁止纯文生图。

### 4.3 单角色主体段（SUBJECT 位）
每位按第三节锁定卡填：`<发型发色> + <瞳色> + <服装逐件> + <道具> + <姿态>`。

moss green eyes, plain white knee-length work coat with no insignia, white shirt open at collar,

## 五、避坑清单（血泪版 · 直接决定返工次数）

1. **遮挡方向必须显式写**。红框标注表达不了「身前/身后」，一句 `behind his back` 省掉三轮返工。
2. **尺寸上限 = 1536×2304**，2048×3072 会被拒。需要更大走「1536 定稿 → 后期放大」。
3. **高清只能原生出**：用 `quality: high` 一步出图；源图软，后期 enhance 救不回来。
4. **禁止全局抬白场修肤色** → 必造白斑（白癜风块）。
5. **「花/斑驳」是细尺度（1–8px）问题**：低频/频域/保边滤波都治不到根，且会把脸磨平。
6. **不要跨版本贴脸**：低版本分辨率低，放大后高频全糊（差异 96% 只是分辨率差）。
   要换脸 → **同源重出**新图（构图对齐 <1px）再整片移植皮肤，掩膜排除虹膜与线稿。
7. **负反馈要枚举**：只写「不要 AI 感」无效，要写「不要削发量 / 不要删肩章 / 不要改披风」。
8. **人物不纯文生图**：必须以原画或已定稿立绘做 i2i。
9. **修图后必检**：脸上无白斑、掩膜外像素 0 改动、虹膜完好。出图后**务必裁特写放大看一遍**——
   ENTJ 那次「左胸徽章叠成两个」在全图缩略下根本看不出来。
10. **绝不在已迭代过的图上继续叠**：每轮 i2i 都会重新采样，**模糊是累积出来的**。
    每次修改都从**原始母版或最新一版高清图**出发，且一轮只改一处。
    源图不足 1536 时，顺手**升到 1536×2304 原生出图**——比事后锐化有效得多。
11. **「紧致」与「通透」是一对张力**：先做紧的结构（发髻收拢），再单独加碎发，分两步、每步一个变量；
    一次性要求「既利落又自然」几乎必然得到一个折中的僵硬结果。
12. **术语与尺寸都要先对齐再出图**：「领花」在本企划 = **小面积实心布艺花边**——
    不是金属领针（太小），也不是大片蕾丝 jabot（太大太夸张）。
    中文服装词歧义大（领花 / 领章 / 领饰 / 领针），且同一个词的**尺寸档位**能差十倍；
    **拿不准时先写「形态 + 材质 + 相对尺寸（占领口/手掌的比例）」，最后才给名称。**
    另外：**「低调」是强约束**——凡作者说「低调/别太夸张」，都要在负面里把
    `large / oversized / dramatic / draping over the chest` 一并写死。
13. **「低调」≠ 省结构**：小面积物件依然要有它该有的**结构**（褶皱 / 层次 / 体积），
    否则同样的轮廓会被读成「一块平板」。**尺寸与结构是两个独立维度**，prompt 里必须分开点名；
    只写 `small and understated` 会把模型推向「平滑无特征」。
    同理，**改 A 时要把不动的 B、C 显式冻结**（写清「尺寸/位置/材质保持不变，只加褶皱」）。
14. **i2i 多轮必然软化，可用「细节回填」救回**：若已迭代数轮且手上还留着更锐利的中间版，
    可「以最新版为底 + 把锐利版的细尺度细节层叠回」——
    `detail = ref - GaussianBlur(ref, σ≈1.6)`，`out = base + detail × 0.88 × (1 - 改动区掩膜)`，
    改动区（如新换的领花）用羽化掩膜排除以免打架。
    实测平均梯度 **4.25 → 4.62**（该图锐利基准 4.75）。
    脚本 `tools/entj_detail_restore.py`；锐度度量 `tools/entj_sharp.py`（脸部区域 Laplacian 方差 + 平均梯度）。
    **前提是两版构图对齐**：先算灰度绝对差，`mean < 5` 才可用，否则会出双影。
    另注：**锐度只能这样"取回"，不能靠事后锐化凭空造出**——原图（1024）本来就没有的细节，放大也变不出来。
15. **「衣服残破」要拆成两类，用两种完全不同的手段**：
    - **结构破损**（破洞 / 撕裂 / 露内衬 / 磨穿的下摆）= **重出图**。走 4.4 的 i2i 模板，
      把「保持不变清单」列全，唯一改动项写「把破损处补成完整结实的布料」，负面钉死
      `no holes / no tears / no ripped / no frayed edges / no exposed lining / no crumbling hem`。
      顺手如果源图 <1536，一并升原生（ISTP 就是这么做的：1024 → 1536）。
    - **表面斑驳**（磨白 / 水渍 / 灰块，但布料本身没破）= **局部算法修正**，**不要**再过一遍 i2i。
      即使用现成的高清图做底，再叠一轮 i2i 仍会软化（第 10 条），而斑驳只是低频色偏，
      用不到重画。见 `tools/istp_coat_even4.py`：
      * 应用域 = 绿色布料掩膜（`g>=r & g>=b`，**只做 3×3 闭运算、绝不膨胀**，
        膨胀会越界到相邻的裤子 → 出现方块伪影）；
      * 判定 = 大衣内 **`L - Lbase > thr`（单向，只压亮斑）** 且 **`Sbase - S > 0.02`（偏灰）**，
        连通域面积 ≥ 60 才处理。**单向是关键**：用 `|L-Lbase|` 会把线稿/阴影边也选中，削弱线条；
      * 底色 `Lbase / Sbase / Abase / Bbase` 的计算域取**非背景全图**（稳健，
        避免掩膜稀疏导致归一化模糊失真、进而误伤掩膜外区域）；
      * 修正 `X -= K · sel · (X - Xbase)`，`K≈0.85`，sel 羽化后**再次强制锁在掩膜内**（掩膜外 0 改动）。
      实测：大衣内平均亮度偏差 13.5 → 11.7，掩膜外改动像素 = 0，裤子零损伤，
      统一归一化到 1024px 宽后平均梯度仅 25.37 → 24.63（-2.9%）。
